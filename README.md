# 아침 투자·부동산 브리핑

평일 아침마다 미국·국내 증시, 환율·금리, 수도권 부동산 소식을 한 페이지로 정리합니다.
출근길에 1분 안에 읽을 수 있는 분량을 목표로 합니다.

**브리핑 보기:** https://geonhyeock.github.io/morning-briefing/

## 담는 내용

| 항목 | 내용 |
| --- | --- |
| 미국 증시 | S&P500·나스닥·다우 종가와 등락률, 움직인 이유, 주요 종목·이벤트 |
| 국내 증시 | 코스피·코스닥 종가와 등락률, 외국인·기관 수급, 주목할 일정 |
| 환율·금리 | 원/달러 환율, 미국 10년물 금리, 한국은행·연준 소식 |
| 수도권 부동산 | 서울·경기·인천 매매·전세 동향, 대출·세금·청약·공급 정책 변화 |
| 오늘 체크할 것 | 그날 가장 주목할 일정이나 지표 1가지 |

## 작성 원칙

- 최근 24시간 이내 기사만 사용하고, 각 브리핑 하단에 출처 링크를 남깁니다.
- 확인하지 못한 수치는 추측하지 않고 "확인 불가"로 표기합니다.
- 휴장일에는 그 사실을 적고 직전 거래일 기준으로 작성합니다.
- 매수·매도 추천 없이 사실과 맥락만 다룹니다.

## 갱신 방식

평일 오전 8시(KST)에 Claude 예약 작업이 웹 검색으로 소식을 모아 `index.html`을 갱신합니다.
최신 브리핑이 맨 위에 오고, 지난 브리핑은 아래에 날짜별로 남습니다.

## 페이지 형식 (자동 작성 규칙)

`index.html` 한 파일에 모든 브리핑을 담습니다. 예약 작업은 이 규칙을 따르고, 형식을 바꾸면 이 절도 함께 고칩니다.

- 새 브리핑은 `<!-- BRIEFINGS:START ... -->` 주석 바로 아래에 `<article id="YYYY-MM-DD">`로 추가합니다. 같은 날짜가 이미 있으면 그 article만 교체합니다.
- article 구성 순서: 제목(`M월 D일(요일) 브리핑`) → 작성 기준(종가 기준일·휴장 여부) → 총평 1줄 → 미국 증시 표(지수·종가·등락률) → 국내 증시 표(지수·종가·등락률·외국인·기관) → 환율·금리 표 → 수도권 부동산 표(지역·매매·전세)와 정책 2~3개 → 오늘 체크할 것 → 내 집 마련 관점 1줄 → 출처(최대 5개).
- 상승은 `class="up"`(빨강), 하락은 `class="down"`(파랑)으로 표시합니다.
- 오래된 브리핑은 최근 30개까지만 남기고 그보다 오래된 article은 삭제합니다.
- 토큰·계정 정보 등 민감정보는 페이지, README, 커밋 메시지 어디에도 넣지 않습니다.

## 유의 사항

이 브리핑은 AI가 공개된 기사를 바탕으로 자동 작성한 참고 자료이며, 투자 권유나 투자 자문이 아닙니다.
수치에 오류가 있을 수 있으니 중요한 판단 전에는 원문 기사와 공식 자료를 확인해 주세요.
